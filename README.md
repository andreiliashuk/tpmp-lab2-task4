# tpmp-lab2-task4 - Работа с текстовыми файлами в C

## Overview
Программа для обработки данных о владельцах автомобилей.
Читает данные из текстового файла, находит владельцев автомобилей марки "ВАЗ"
и сохраняет результат в отдельный файл.

## Author
Андрей Ляшук, группа 10

## Usage
1. Сборка программы:
make

2. Запуск программы:

./bin/program
text


3. Очистка:

make clean



## Additional Notes
Программа следует модели КИС:
- `main.c` - клиентская часть
- `car_owner.h` - интерфейс (структура и прототипы)
- `car_owner.c` - серверная часть (реализация)

Входной файл: `data/owners.txt`
Выходной файл: `data/vaz_owners.txt`
