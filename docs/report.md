## Описание программы
Программа обрабатывает данные о владельцах автомобилей:
1. Создаёт пример текстового файла `data/owners.txt` с 5 записями
2. Читает и отображает все записи
3. Фильтрует записи по марке "ВАЗ"
4. Сохраняет результат в `data/vaz_owners.txt`

## Структура проекта (модель КИС)
- `src/car_owner.h` - интерфейс (структуры и прототипы)
- `src/car_owner.c` - сервер (работа с файлами и фильтрация)
- `src/main.c` - клиент (основная логика)
